# 接口协商清单（独立前端联调版）

联调基线已固定为：**`gnnwr_platform_frontend` × `llzays-eng/gnnwr_platform_backend`（PR #1+）**。  
本清单用于记录「仍未冻结」与「本轮已解冻」的状态，真相源同步在 `src/shared/api/endpoints.ts`。

> `VITE_MOCK_ASSUME_PENDING_CONTRACTS` 的默认建议为 `false`：联调时优先暴露契约缺口。  
> 如需纯 Mock 演示剩余 PENDING 功能，可临时设为 `true`。

| # | 能力 | 状态 | 当前前端策略 |
|---|---|---|---|
| 1 | WS payload 与鉴权 | **FROZEN（主路径）** | 使用 `/ws/models/tasks/{task_id}?token=`；无 `coef_summary` 时 UI 自动降级 |
| 2 | 分片上传 / 断点续传 | **FROZEN（本轮解冻）** | 走 `upload/init → chunk → complete`；若接错旧后端会提示并回落单次上传 |
| 3 | 逐点系数分页 / bbox 裁剪 | **FROZEN（本轮解冻）** | 始终按 WGS84 bbox 增量查询，LRU 缓存 |
| 4 | 曲面切片坐标系 | **FROZEN（后端自渲染）** | 读取 `tile_crs`；非匹配底图 CRS 时显式告警偏移风险 |
| 5 | 任务取消 / 日志 | **FROZEN（本轮解冻）** | 启用真实 cancel/logs 客户端 |
| 6 | 配置模板 | **PENDING** | 继续 localStorage，界面标注「仅本机可见」 |
| 7 | 报告导出异步 job | **PENDING** | 保持运行时探测（blob vs JSON job）兼容两种后端 |
| 8 | 登出 | **FROZEN（本轮解冻）** | 调用 `/auth/logout`；失败也清本地凭据 |
| 9 | 项目/数据集/任务列表 | **FROZEN（本轮解冻）** | 使用真实分页列表接口，不再走 pendingContract |
| 10 | GeoServer 代理鉴权 | **已被替代** | 改为后端 `/spatial/surface` 自渲染曲面 + `sig` 签名 URL |
